# TABStudio

[English](#english) | [日本語](#日本語)

---

## English

**Tablature, full band, solo.**

TABStudio is a Windows application that displays and plays back Guitar Pro
tablature files, and lets you practice with VST3 instruments and VST3
effects.

### Early Support

TABStudio is currently available as an Early Support release.

- The app itself is a free download
- Regular use requires a monthly subscription
- The first week is free
- Subscription and cancellation are managed through Microsoft Store

TABStudio is currently available on the Microsoft Store.

[Get TABStudio from the Microsoft Store](https://apps.microsoft.com/detail/9MT8TB5WQT07)

### Key Features

- Load Guitar Pro format (GP3–GP8) tablature
- Switch between tablature and standard notation display
- VST3 instrument (VSTi) support
- VST3 effect support
- Per-track instrument settings
- Track mixer
- Mute / solo playback
- Playback speed control
- Loop playback
- Guitar input via audio interface
- Apply VST3 effects to guitar input

### Current Limitations

- AI-based transcription is not available in the current public release
- Some features may be under development or experimental

### Support

Help, FAQ, bug reports, and the privacy policy will be added to this
repository over time.

Bug reports will be accepted via
[Issues](https://github.com/Yumeakari-do/tabstudio-product/issues).

## 日本語

**一人でも、フルバンド。**

TABStudioは、Guitar Pro形式のTAB譜を表示・再生し、VST3音源やVST3エフェクトを組み合わせて練習できるWindowsアプリです。

### Early Support

TABStudioは現在、Early Support版として準備中です。

- アプリ本体は無料でダウンロード
- 通常利用には月額サブスクリプションが必要
- 最初の1週間は無料
- 契約・解約はMicrosoft Storeを通じて管理

現在、Microsoft Storeで公開中です。

[Microsoft StoreでTABStudioを入手](https://apps.microsoft.com/detail/9MT8TB5WQT07)

### 主な機能

- Guitar Pro形式（GP3～GP8）のTAB譜読み込み
- TAB譜・五線譜の表示切り替え
- VST3音源（VSTi）対応
- VST3エフェクト対応
- トラックごとの音源設定
- トラックミキサー
- ミュート・ソロ再生
- 再生速度変更
- ループ再生
- オーディオインターフェース経由のギター入力
- ギター演奏へのVST3エフェクト適用

### 現在の制限

- AI採譜機能は現在の公開版では利用できません
- 一部に開発中・実験的な機能が含まれる場合があります
